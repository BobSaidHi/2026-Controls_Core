# 2026-Controls_Core

Shared files, issues and examples for 2026 Controls. To be included as a submodule, in the `lib` folder, in the [nacelle](https://github.com/CalPolyWindPower/2026-Controls_Nace) and [Load](https://github.com/CalPolyWindPower/2026-Controls_Load) controllers.

## Folder/ Directory Structure

- `.github` - GitHub config
- `.vscode` - VSCode config
- `2026Core` - Library root
  - `Net` - Old Network stuff, partially maintained by @BobSaidHi. Turned out this much abstraction to make networking implementations interchangeable was more trouble than it was worth
    - `Net-Application` - Network layer network stuff
    - `Net-Link` - Link layer network stuff
    - `Net-Phy` - Physical layer network stuff
    - `NetAdapter_A` - Abstract class describing necessary components & interface to send data
  - `TurbinePacket` - Network data format specification and usage example
  - ~~`PID` - PID stuff~~
  - `CommonConfig.hpp` - Shared configuration.  Turns out a lot of config is controller specific.
  - `Tags.hpp` - Shared TAGS for ESP logging (incomplete)
- `docs` - documentation
  - `config` - Doxygen config
  - `cpp` - Notes on C++
  - `doxygen-out` - Autogenerated Doxygen API dos
  - `FSM` - Shared FSM diagramming and planning
  - Miscellaneous Windows Scripts/ batch files (`.bat`)
- `Hardware-Devboard` - Development board selection
- `Hardware-Pinouts` - Development board pinouts
